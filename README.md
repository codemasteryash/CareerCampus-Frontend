## 🚀 Quick Start

### Prerequisites
- Node.js 18+
- Backend running at `http://localhost:8080` ([Backend Repo](https://github.com/codemasteryash/CareerCompass))

### 1. Clone the repo

```bash
git clone https://github.com/codemasteryash/CareerCompass-Frontend.git
cd CareerCompass-Frontend
```

### 2. Install dependencies

```bash
npm install
```

### 3. Configure environment

Create `.env.local` in the project root:

```env
# Leave empty for local dev — Vite proxy handles it automatically
# VITE_API_BASE_URL=
```

The Vite dev proxy in `vite.config.js` automatically forwards `/api/*` requests to `http://127.0.0.1:8080` — no CORS config needed locally.

### 4. Start the dev server

```bash
npm run dev
```

Open **http://localhost:5173** 🎉

### 5. Build for production

```bash
npm run build
```

Output goes to `dist/` — ready to deploy to any static host.

## 🔌 How the API Layer Works

Every API call follows this path:

```
Component
   │
   ▼
api/endpoints/skill.js          → skillApi.getMySkills()
   │
   ▼
api/axios.js                    → api.get('/skills/me')
   │                              baseURL: VITE_API_BASE_URL || '/api'
   ▼
Request Interceptor              → reads JWT from Zustand
   │                              adds Authorization: Bearer <token>
   ▼
Vite Proxy (dev) /               → forwards to http://127.0.0.1:8080/api/skills/me
Vercel → Render (prod)
   │
   ▼
Spring Boot Backend              → validates JWT, queries DB, returns JSON
   │
   ▼
Response Interceptor             → if 401: logout() + redirect to /login
   │                              else: pass through
   ▼
Component .then(res => ...)      → update state → React re-renders
```

## 🔐 Auth Flow

```
Register / Login
      │
      ▼
authApi.register() / authApi.login()
      │
      ▼
Backend returns { token, name, email, targetJobRole }
      │
      ▼
useAuthStore.login(token, user)         ← Zustand store
      │
      ▼
persist middleware saves to localStorage ← stays logged in on refresh
      │
      ▼
navigate('/dashboard')

─────────────────────────────────────

Token expires (7 days)
      │
      ▼
Any API call → backend returns 401
      │
      ▼
Axios response interceptor catches it
      │
      ▼
useAuthStore.logout()                   ← clears localStorage
      │
      ▼
window.location.href = '/login'         ← hard redirect
```

## 🌍 Deployment

Deployed on **Vercel** with automatic deployments on every push to `main`.

### Manual Deploy

```bash
# Install Vercel CLI
npm i -g vercel

# Deploy
vercel --prod
```

### Required Environment Variable

```
VITE_API_BASE_URL=https://your-render-backend.onrender.com/api
```

### `vercel.json` — Critical for SPA routing

```json
{
  "rewrites": [
    { "source": "/(.*)", "destination": "/index.html" }
  ]
}
```

Without this, direct URL access (e.g. `/dashboard`) returns 404 because Vercel looks for a physical file at that path. The rewrite tells Vercel to always serve `index.html` and let React Router handle navigation.

## 🧩 Key Patterns Used

| Pattern | Where | Why |
|---------|-------|-----|
| **Loading / Error / Data** | Every page | Consistent UX across all data fetches |
| **Optimistic updates** | Skills, Roadmap steps | Instant UI feedback before API responds |
| **Pre-run state** | Analysis, Projects, Certifications | Avoid unnecessary AI calls on page load |
| **Expand / Collapse** | Roles, Projects, Roadmap | Progressive disclosure — scannable at a glance |
| **Alert timeout** | All mutation actions | Temporary feedback without permanent UI clutter |
| **Controlled inputs** | All forms | Full control for validation and submission |
| **getState() outside React** | Axios interceptor | Read Zustand store without violating hook rules |
